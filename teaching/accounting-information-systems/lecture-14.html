Microteach 14.1 · 1:00Robotic process automation

Robotic process automation, or RPA, uses software bots that mimic a person: clicking through screens, copying data and following rules.

Read the script

Some of the newest members of the accounting team are software robots.

Robotic process automation, or RPA, uses software bots that mimic a person: clicking through screens, copying data and following rules.

Bots suit repetitive, rule-based tasks: entering invoice data, matching bank transactions, uploading journal entries, and downloading and emailing reports.

Common tools include UiPath, Automation Anywhere and Microsoft Power Automate.

Bots need controls too. Each bot needs its own credentials with limited access, changes to bots need approval, and every action should be logged.

So bots handle the rules, and accountants handle the judgment.

Quick check. RPA is best suited to which kind of task? Pause and pick.

Repetitive, rule-based tasks.

Microteach 14.2 · 1:04AI and machine learning in accounting

Machine learning is a type of artificial intelligence where systems learn patterns from data, instead of following rules a programmer wrote.

Read the script

Machine learning can read invoices, forecast cash, and spot fraud. Here's how.

Machine learning is a type of artificial intelligence where systems learn patterns from data, instead of following rules a programmer wrote.

In accounting, it reads invoices and receipts, matches payments to invoices, forecasts cash flow, and detects anomalies that might be errors or fraud.

Anomaly detection learns what normal transactions look like, then flags the unusual ones: an odd vendor, an odd time, an odd amount.

The risks: biased or poor training data, decisions that are hard to explain to auditors, and users trusting the output without checking it.

So machine learning learns from data, but it still needs human review.

Quick check. Using machine learning to flag unusual transactions is called what? Pause and pick.

Anomaly detection.

Microteach 14.3 · 1:12Generative AI and its controls

Generative AI, built on large language models, creates new text, code and images.

Read the script

Generative AI can draft a memo in seconds. It can also make up numbers that look completely real.

Generative AI, built on large language models, creates new text, code and images. ERP vendors are now building AI copilots into their systems.

Accountants use it to draft variance commentary, summarize contracts, answer policy questions, and write SQL queries or spreadsheet formulas.

The key risks: hallucinations, where the AI states wrong facts confidently; leaking confidential data into public tools; inconsistent answers; and an unclear audit trail.

Controls: use only approved tools, keep sensitive data out of public AI services, require human review of every output, and log prompts and responses.

So: draft with AI, but verify like an accountant.

Quick check. When generative AI states false information confidently, what's that called? Pause and pick.

A hallucination.

Microteach 14.4 · 1:09Blockchain and distributed ledgers

A blockchain is a distributed ledger: a shared record copied across many computers, with transactions grouped into blocks linked by cryptography.

Read the script

What if every company in a supply chain shared one ledger that nobody could secretly change?

A blockchain is a distributed ledger: a shared record copied across many computers, with transactions grouped into blocks linked by cryptography.

Its key features: it's distributed across many copies, very hard to change once recorded, visible to participants, and new blocks are added only by consensus.

Smart contracts are programs on the blockchain that execute automatically, such as releasing payment when a shipment is confirmed.

For audit, blockchain can provide shared evidence and reduce the need for confirmations. But a transaction being on a blockchain doesn't make it legitimate or correctly valued, and private keys and smart contract code bring new risks.

So remember: tamper-evident does not mean error-free.

Quick check. Code on a blockchain that executes automatically is called what? Pause and pick.

A smart contract.

Microteach 14.5 · 1:11Process mining

Process mining uses the event logs in ERP systems, every timestamped step, to reconstruct how processes actually run.

Read the script

Your process map says one thing. Your ERP's data might say something very different.

Process mining uses the event logs in ERP systems, every timestamped step, to reconstruct how processes actually run.

Each event log entry records a case, like purchase order forty-five twelve, an activity, like create PO, and a timestamp. String them together and you see the real process.

It reveals bottlenecks and delays, skipped approval steps, invoices received before a purchase order existed, and rework loops.

Tools like Celonis, along with process mining built into SAP and Microsoft products, make this widely available.

For auditors, it's powerful. You test every transaction's actual path, not the process someone described in an interview.

So the data shows the real process, not the one on the wall chart.

Quick check. Process mining reconstructs processes from what? Pause and pick.

Event logs.

Microteach 14.6 · 1:09Course recap: the AIS in 2 minutes

We started with the AIS: people, procedures, data, software, infrastructure and controls, turning data into decisions.

Read the script

Fourteen lectures, two minutes. Here's the whole course.

We started with the AIS: people, procedures, data, software, infrastructure and controls, turning data into decisions.

You learned the tools: documenting processes, relational databases and SQL, and ERP systems like SAP, Oracle, Dynamics, Workday and NetSuite.

You followed the five cycles: revenue, expenditure, production, and HR and payroll, all feeding the general ledger.

Then control and audit: the fraud triangle and SOX, the COSO and COBIT frameworks, IT controls, and auditing with analytics.

And the future: automation, AI and blockchain. The tools will keep changing, but the principles stay the same.

Thanks for learning with me. Good luck on the final exam.
